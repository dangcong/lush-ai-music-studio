Quy tắc

  • Chỉ tự viết khi có file reference. Gỡ file thì prompt đã điền vẫn giữ.
  • Không bao giờ ghi đè chữ bạn đã gõ; “Viết lại” cho model nghe lại và thay prompt (bấm Ctrl+Z / “Hoàn tác” để lấy lại bản trước).
  • Không cần chờ: bấm Generate lúc đang nghe thì tạo nhạc với prompt hiện có (có thể trống).
  • Lỗi hoặc máy render tắt: hiện “Không viết được prompt · Thử lại”, phần còn lại vẫn dùng bình thường.
  • Tempo/Key đo bằng librosa (như Catalog), chỉ là gợi ý.
